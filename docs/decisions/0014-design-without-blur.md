# 0014. Pre-baked pixels instead of blur, backdrop-filter and animated shadows

Status: accepted
Date: 2026-09-04

## Context

The brief bans `filter`, `backdrop-filter`, animated `box-shadow` and large blurs, because
MCU 2 is an Intel Atom and each of those is a full-surface repaint. Those are also the four
things every "premium" interface reaches for first.

## Decision

Depth comes from pixels that were computed once:

| Effect | How |
|---|---|
| Car glow | a radial gradient rasterised into the sprite bitmap, per (model, colour, dpr) |
| Frosted sheet | flat colour at 94% plus a tiled 160x160 noise PNG at ~4% |
| Vignette | one fixed element with a static gradient, painted once, never animated |
| Ripples, pulses, sonar | canvas arcs with `globalAlpha`, or DOM elements animating `transform` and `opacity` |
| Depth on a sheet | a hairline border and an entry transform, not a shadow |

Motion is composited: `transform` and `opacity`, full stop. `scripts/check-css.mjs` enforces
all of this at build time, including a ban on hardcoded screen sizes, because 2026.26 changed
the car browser's pixel density and broke apps that assumed one.

## Rejected alternatives

- **Feature-detecting and degrading**: two designs to maintain, and the degraded one is what
  most drivers would see.
- **Deciding by user agent**: the Tesla browser is Chromium; there is nothing honest to sniff.
  Frame rate is measured instead, and the overlay drops to 30 fps when frames run long.

## Consequences

The textures are generated by `scripts/gen-textures.mjs` (pure Node, no dependencies), so a
rebrand regenerates them. The rule is not a suggestion: a lint failure names the file, the
line and the reason.
